X 关注清理 · 一键书签

安装后不用再复制粘贴代码，打开关注页点一下就跑。

安装（做一次就行）

  1. 显示书签栏：Cmd + Shift + B（Chrome / Edge / Brave 通用）
  2. 把下面两颗按钮拖到书签栏松手
  3. 打开 x.com/你的用户名/following
  4. 先点「预览」看它圈得准不准，认可了再点「执行」

两颗书签

预览（不删人） DRY_RUN = true ｜ MIN_SCORE = 40

只列出它认为该删的账号，一个都不动。第一次一定用这颗。

预览（不删人）

↑ 按住这个按钮，拖到浏览器书签栏松手

执行（真删） DRY_RUN = false ｜ MIN_SCORE = 40

真正取关。脚本跑满 50 个自动停，自带 15–40 秒随机延迟。

执行（真删）

↑ 按住这个按钮，拖到浏览器书签栏松手

注意
· 滚动期间不要切走标签页，浏览器会暂停后台滚动，脚本会卡住（看着像死了，其实只是被冻住）。
· 每日取关不超过 100 个，脚本自带随机延迟，别改小。
· 跑完会自动下载 cleanup_log.json，误删了照着名单加回来。
· 想改判定标准：编辑 x_smart_unfollow.js 的 WEIGHTS，再跑一次 python3 make_bookmarklet.py，书签自动同步。
