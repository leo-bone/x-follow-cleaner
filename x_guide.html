X（推特）关注清理工具包 v2

按「账号是否优质」的多维框架打分 · 先审计 → 可精评 → 后执行
⚠️ 三条硬规则：
1. 我无法替你登录 X。取关动作必须由你在自己浏览器里跑脚本完成。
2. 封号风险：保持随机延迟、每日 ≤100、分多天；先预览（DRY_RUN）、先小批量。
3. 取关不可自动撤销。务必保留白名单、先核对名单。

评分框架（分越高越该删，负分=建议保留）

优先级维度权重说明
1内容质量核心本身是否产出好内容；不能只看多久没发帖（脚本代理：简介真实度）
2被有价值的人关注核心社会证明/声望（脚本代理：蓝标 −25、粉丝>1万 −15）
3营销 / 诈骗密度该删 +35简介/昵称含推广、代购、资金盘、稳赚等话术
4AI 化该删 +20fully automated、🤖、auto-post 等机器人特征
5互关太多该删 +15关注数远多于粉丝数（互关党）
6是否关注我（回关）最末 +5 / −5只是弱信号，不再主导
补充维度：简介空洞 +15、默认头像 +5、老账号(>3年) −10、简介有实质 −10。 全部权重在 x_score.py 顶部，可自行调整。
数据边界（必须知道）：following 列表页只能拿到 handle / 简介 / 是否回关。 「粉丝数、关注数、蓝标、最近发帖」必须进每个 profile 才看得到 —— 这是 x_deepscan.js 的作用。 而框架第 1（内容质量）与第 2（被谁关注）的最终判断，仍需你人眼抽样看推文和关注者构成； 脚本只做第一关过滤（营销/AI/简介空洞 + 蓝标/粉丝/互关比）。

工具清单

x_audit.js   → 审计：抓全部关注，导出 JSON（只读，不删人）
x_deepscan.js → 精评：逐个 profile 抓 粉丝/关注/蓝标/发帖（Tampermonkey）
x_score.py   → 打分：合并上述数据，出报告 + 取关名单
x_smart_unfollow.js → 一步式：滚动 + 实时评分 + 取关（推荐）
x_unfollow.js → 精确名单式取关：带白名单/随机延迟/上限/预览
x_guide.html → 本页

阶段 A · 快速筛选（必做）

1
打开 x.com/你的用户名/following，F12（Mac Cmd+Option+J）粘贴 x_audit.js 运行 → 下载 following_audit.json。3000+ 会滚几分钟，别切走。
2
同目录跑 python3 x_score.py → 基础报告：红=该删(≥20)、黄=待定(0–19)、绿=保留(<0)。
3
「该删」档直接确认；「待定」档若拿不准，进入阶段 B。

阶段 B · 精评（可选，针对待定档）

4
装 Tampermonkey 扩展，把 x_deepscan.js 存为用户脚本（已带 @match https://x.com/*）。
5
把待定档 handle 填进 TARGET_HANDLES，打开 x.com，脚本自动链式跳 profile 抓取，完成下载 deepscan.json。
建议单批 ≤200、间隔 5–10 秒、分多天。纯控制台粘贴也能启动，但跳转后需重新粘贴，故推荐 Tampermonkey。
6
把 deepscan.json 与 following_audit.json 放同目录，重跑 python3 x_score.py → 框架 1/2/5 维度被计入，报告更准。

一步式路径（推荐：不想导 JSON、不想跑 Python 就走这条）

★
打开 following 页，F12 粘贴 x_smart_unfollow.js。 它在页面里实时按 v2 框架打分，MIN_SCORE（默认 20）以上且不在白名单的自动取关， 边跑边打印「@handle + 分数 + 原因」。想更保守就把阈值调到 40（只删最恶劣的）。
!
务必先 DRY_RUN=true 预览一遍， 确认判定符合你的直觉，再改 false 执行。
一步式拿不到蓝标/粉丝数（following 页面没有），所以默认只算「营销 / AI / 简介 / 回关」四项。 若想让它也计入蓝标、粉丝、互关比，把 x_deepscan.js 抓到的数据填进脚本顶部的 EXTRA_DATA。

阶段 C · 取关（谨慎）

7
名单填进 x_unfollow.js 的 TARGET_HANDLES，重要账号填 WHITELIST。
8
先 DRY_RUN=true 预览，确认只有想删的人，再改 false 执行。每日 ≤100、每批 ≤50。
最简路径：只跑阶段 A 就能砍掉绝大部分明显营销 / AI / 简介空洞的账号。 阶段 B 用在「互关的真实人」里难以决断的那批。别为追求完美卡在 B —— 人眼抽看 20 个， 比自动抓 2000 个信息量更大。
