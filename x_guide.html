评分框架

优先级维度实现
1内容质量简介真实度代理（空洞 +15 / 有实质 −10）
2被有价值的人关注权威认证 −25、机构认证 −25、粉丝>10万 −25 / >1万 −15
3营销 / 诈骗HARD 黑产 +35 / SOFT 商业化 +12（分级，防误杀）
4AI 化+20（含中文自动号：「自动抓取/定时推送」）
5互关太多重度 +25 / 中度 +8 / 关注数>5000 +12
6是否回关你未回关 +5（很弱）；互关 −10 仅作误删保护垫

五项防误删设计

  • 营销词分级 —— link in bio、linktr.ee、推广 正经创作者也用，一刀切 +35 会误杀
  • 可信身份豁免 —— 「Crypto researcher, ex-JP Morgan」不该被当成诈骗号删掉
  • 蓝标分级 —— 2026 年蓝标 = 付费订阅谁都能买，只有 legacy/business 才算社会证明
  • 互关比双条件 —— 比值 + 绝对关注数，避免误伤「关注 3100 / 粉丝 900 的产品设计师」
  • handle 随机数字串 —— 批量号最廉价的指纹
★ 变质号识别
最该删的往往不是垃圾号，而是「关注时是好号、后来变质的号」—— 老号、真粉丝、每个结构信号都正常， 只有当前行为能暴露。普通工具里「老账号 −10」会把「营销 +35」抵消成 20 分待定，放走最该删的号。 本引擎命中营销时取消老号加分，反追加「★老号变质」+10。

⚠️ 安全（务必阅读）

  • 每天 ≤100 个，分多天做，每批 ≤50。 手动删 200+ 大概率没事，但别连续高量。
  • 脚本内置随机延迟 15–40 秒/次，模拟人类手速抖动，规避匀速检测。
  • 断点续跑存在 localStorage，3000 个中断不用重来。
  • 每次运行导出 cleanup_log.json，误删可据此恢复。
  • X 的限制常是延迟生效，出现「操作受限」提示立即停 48 小时。

已知局限（实话）

  • 框架 1（内容质量）和框架 2（被谁关注）的最终判断只能靠人眼。脚本做的是第一关过滤， 剩下的「互关的真实人」里挑，抽看 20 个比自动抓 2000 个信息量大。
  • following 列表页看不到粉丝数/关注数/认证类型，需要 x_deepscan.js 补。 数据完整度低于 60% 时报告会明确提示。
  • 执行安全性不如官方 API 工具（Circleboom 走官方 API 被 X 认可；本项目是浏览器脚本模拟点击）。 只能靠延迟和分批缓解。
